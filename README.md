AdBlock++ 3.2 — инструменты для обработки выделенного текста

УСТАНОВКА
1. Распакуйте ZIP и перейдите в chrome://extensions/.
2. Включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
3. Выберите папку NEV_Cheats.
4. Нажмите на значок AdBlock++ на панели расширений: откроются настройки.
5. Вставьте НОВЫЙ ключ OpenRouter (старые ключи, опубликованные в чате, лучше отозвать), нажмите «Сохранить» и «Проверить ключ».
6. Нажмите «Проверить модель» для полного тестового API-запроса.
7. Проверьте назначения клавиш в chrome://extensions/shortcuts.

ИСПОЛЬЗОВАНИЕ
- Выделите текст на обычной странице http:// или https://.
- Alt+X: обработать и скопировать результат (без появления ответа на странице).
- Alt+Z: сразу показать бледную надпись обработки, затем полученный ответ справа снизу. При наведении он становится более заметным, при отведении — бледным.
- Наведение на нижний левый угол показывает диагностические логи.
- Через 15 секунд ПОСЛЕ ответа или ошибки ответ полностью прозрачен. Наведение вновь показывает его, даже после истечения таймера. Миниатюрный индикатор сверху исчезает.
- Скопированный текст в буфере обмена остаётся.
- Пока действует кэш, повторная команда с тем же выделением не вызывает API снова.
- Также доступно контекстное меню «Обработать выделенный текст».

ИЗМЕНЕНИЯ В ВЕРСИИ 3.0–3.2
- Исправлено несовпадение AI_GENERATE/ASK_AI.
- Добавлены обработчики chrome.commands.onCommand и контекстного меню.
- Контент-скрипт подключается только по действию пользователя, а не на каждой странице.
- Добавлены настройки и тест ключа (GET /api/v1/key), тест модели.
- API-ключ не хранится внутри background.js и ZIP; он вводится через настройки.
- Добавлены тайм-ауты, обработка HTTP-ошибок и пустых ответов.
- Обновлено копирование в буфер обмена и предотвращено дублирование запросов.
- Изоляция интерфейса через Shadow DOM, невидимые маленькие зоны наведения.

ВАЖНО
- Не используйте расширение для отправки паролей, личных данных и секретов.
- Бесплатный endpoint NVIDIA может регистрировать запросы. Политику см. на OpenRouter.
- Внутренние страницы браузера и Chrome Web Store не позволяют внедрять контент-скрипты.
- Если клавиша не срабатывает, проверьте chrome://extensions/shortcuts.
- Настройки хранятся в профиле Chrome (chrome.storage.local), не в системном хранилище секретов.
- Это инструмент для текста и НЕ является блокировщиком рекламы.

Версия 3.2: Alt+Z сразу показывает бледный индикатор обработки и затем ответ; при наведении текст становится более заметным, при отведении вновь бледнеет. Через 15 секунд после ответа/ошибки текст становится полностью прозрачным, но снова проявляется при наведении (без повторного API-запроса). Индикатор также скрывается, буфер обмена сохраняется. Миниатюрные символы этапов — вверху справа; подробные логи — внизу слева при наведении. Стили встроены в content.js (style.css для этой версии не используется).
